# One-Hour Notebook Lecture: Numerical Solutions of ODEs

- **Course:** Scientific Programming for Physics (Oct 27, 2026)
- **Author:** Durdona Uskenbayeva
- **Advisor:** Aleksandr Kapitonov

## Summary
This repository contains a 60-minute interactive Jupyter notebook lecture demonstrating numerical integration methods for Ordinary Differential Equations (ODEs), including Euler's method, SciPy's adaptive RK45 solver, step-size convergence analysis, harmonic oscillators, stiff solvers (Radau, BDF), and the Van der Pol nonlinear oscillator.

## How to Run
1. Open the notebook in Google Colab using the badge or link.
2. Run all cells from top to bottom ("Run all").
